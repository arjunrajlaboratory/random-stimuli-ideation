## Domain terms and their canonical phrasings
- "prompt" or "method" = one arm: a way of asking for ideas, tested with 8 independent calls × 5 ideas per model and question.
- "call" = one fresh-context request; the experimental unit for every test.
- "cell" = one question × model × method (40 ideas).
- "stripped text" = the arm- and model-blind rewrite with analogy, metaphor and framing labels removed (02_strip.py).
- "useful-novel idea" = pass-averaged primary-judge novelty and usefulness both ≥ 4.
- "distinct useful-novel ideas" = useful-novel ideas merged into near-duplicate clusters (stripped MiniLM embeddings, cosine 0.75) within each cell, summed.
- "unrelated-domain instruction" (config label) = the earlier study's "instruction-only" prompt. Use one name consistently.
- "mode collapse" = the model returning the same few most-probable answers.
- Models: Haiku 5.5, Sonnet 5.5, Opus 5.5 (register names as text values; digits in names collide with small integers in the linter).

## Decisions already made (do not relitigate)
- Pre-registration in IDEATION_METHODS_ACROSS_MODELS.md, written before generation; deviations listed there.
- Call is the unit; stratified permutation tests over calls within question × model; Holm over 3 models (H1) and over 7 methods (H2).
- Primary judge Opus 5.5 on stripped text, 2 passes; Sonnet cross-judge and Opus as-written are robustness checks, 1 pass each.
- Safety-classifier stops are recorded, never retried or rephrased.
- The earlier study's main result (unrelated-domain instruction) was exploratory; here it is a pre-specified replication (H1).

## Previously-flagged failure modes (re-check for these in this draft)
- Outcome switching: lead with the pre-registered primary outcome even if null; label secondary outcomes as such.
- State Holm family sizes.
- Verbs next to numbers ("most", "no trace", "planned", "confirmed") must match the registered values (earlier reviewers caught overstatements).
- Raw useful-novel counts reward repetition; use distinct counts.
- Single-example-as-proof; check example claims row by row.
- Identifiers with digits (AP-1, model names, "[1]" citations) collide with registered small integers in scitexlintr: register model and factor names as text values, use author-name citation links, write structural counts in words.
- Self-preference: Opus judges Opus ideas; report the Sonnet cross-judge.
