## Domain terms and their canonical phrasings
- "arm" = one prompt type tested with 8 independent calls × 5 ideas = 40 ideas.
- "call" = one fresh-context request to the model; the experimental unit for every test.
- "stripped text" = the arm-blind rewrite with analogies/metaphors removed (06_strip_decoration.py).
- "useful-novel idea" = pass-averaged judge novelty and usefulness both >= 4.
- "distinct useful-novel ideas" = useful-novel ideas merged into near-duplicate clusters (stripped MiniLM embeddings, cosine 0.75).
- "required" wording = "each idea must draw on this material…"; "optional" = "let it inspire you, or not".
- "instruction only" = required-style instruction with no material.
- "parallel-problem essay" = stage-1 essay about a structurally similar problem in another field (stream_parallel_required).
- "verbalized sampling" = ask for N responses with probabilities (Zhang et al. 2025).
- "mode collapse" = the model returning the same few most-probable answers.

## Decisions already made (do not relitigate)
- Call is the unit; permutation tests over calls; Holm within frozen per-phase families.
- Primary embedding metrics spread and near-dup; clusters secondary.
- Judge is Opus 5.5, blind to arm; human ratings are the real readout (pending).
- Safety-classifier stops are not worked around; one v5 batch was re-sent unmodified once (disclose).
- Stage-1 wording uses "associative essay" because "stream of thought / think freely" was refused.
